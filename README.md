# Sistema de Gerenciamento de Academia

## Sobre o projeto

Este projeto é um sistema de gerenciamento de academia desenvolvido em Java. Ele utiliza programação orientada a objetos (POO), organizando o código em classes que representam os elementos do sistema e seus comportamentos.

O sistema é executado pelo terminal/console e apresenta um menu para que o usuário escolha as operações disponíveis.

## Funcionalidades

- Menu interativo no console.
- Cadastro e gerenciamento de informações relacionadas à academia.
- Validação de dados informados pelo usuário, incluindo a verificação do CPF.
- Organização da lógica do sistema em métodos das classes, evitando concentrar todo o comportamento na classe `main`.

> Observação: as funcionalidades exatas disponíveis dependem das opções implementadas no código do projeto.

## Tecnologias utilizadas

- **Java**
- **Apache Ant** para a execução/build do projeto.
- **NetBeans IDE** como ambiente de desenvolvimento.

## Como executar

1. Instale o **JDK (Java Development Kit)**.
2. Abra o projeto no NetBeans.
3. Aguarde o NetBeans reconhecer e carregar o projeto.
4. Localize a classe principal `App.java`, dentro do pacote `academia`.
5. Execute o projeto pelo botão **Run** (Executar) do NetBeans.

Se preferir executar pelo terminal, entre na pasta do projeto e utilize o comando de build compatível com a configuração do projeto Ant.

## Estrutura do projeto

O código-fonte Java fica na pasta `src`, organizado em pacotes e classes. A classe `App` contém o ponto de entrada do programa (`main`) e inicia a interação com o usuário. As demais classes devem concentrar os atributos e métodos referentes às suas responsabilidades.

A estrutura exata de pastas e classes pode variar conforme a versão do projeto.

## Conceitos de programação utilizados

- Classes e objetos.
- Atributos e métodos.
- Encapsulamento, por meio de atributos e métodos de acesso quando aplicável.
- Estruturas condicionais e de repetição.
- Entrada e saída de dados pelo console.
- Validação de dados.
